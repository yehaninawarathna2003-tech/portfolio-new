# portfolio-new

A simple personal portfolio website built with plain HTML, CSS, and JavaScript.

## Description

This repository contains a minimal portfolio site showcasing projects and contact
information. It's intended as a lightweight starter you can customize and deploy
to GitHub Pages or any static hosting provider.

## Project structure

- `index.html` — main site markup
- `style.css` — styles and responsive layout
- `script.js` — interactive behavior
- `assets/` — images and other static assets

## Features

- Responsive, mobile-friendly layout
- Lightweight and easy to customize
- No build step required (static files only)

## Local development

Open `index.html` directly in your browser, or run a simple HTTP server from the
project root. For example, with Python 3:

```bash
python -m http.server 8000

# then visit http://localhost:8000
```

## Customization

- Replace the contents of `index.html` to change page sections.
- Update styles in `style.css` and scripts in `script.js`.
- Add images or media inside `assets/` and reference them from the HTML.

## Deployment

You can deploy this repository to GitHub Pages by enabling Pages in the
repository settings and selecting the `main` branch (or the branch you use).
