UI/UX Design

LKmart – Mobile Accessories Shop

Project Overview

LKmart is a UI/UX design project for a modern mobile accessories shopping platform. The design focuses on creating a simple, attractive, and user-friendly shopping experience where customers can easily browse, explore, and purchase mobile accessories.

The project includes intuitive navigation, product displays, category sections, product details, and a smooth user journey. The interface was designed with a clean and modern visual style to make shopping convenient and enjoyable for users.

Role: UI/UX Designer
Tool: Figma
Focus Areas: User Interface Design, User Experience, Wireframing, Prototyping

Key Design Features

  • Clean, responsive e-commerce layout optimized for mobile & desktop
  • Intuitive category navigation for quick accessory discovery
  • Interactive wireframes and high-fidelity clickable Figma prototype
  • Visual hierarchy tailored for product browsing and cart checkout
